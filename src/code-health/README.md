# Code-health storage and collection seams

This directory contains Heimdall's local persistence, bounded producer admission, and read-only query seams for the frozen Code Health v1 contract. The read-only `/code-health` page and `/api/code-health` endpoint use these stored views; see [`../../docs/code-health.md`](../../docs/code-health.md) for the user-facing contract, configuration boundaries, retention and rollback.

Objective collection is off by default. `collectObjectiveReports({ db, config, transport, clock })` only performs work when `config.enabled === true` and receives a `transport` with authenticated `listArtifacts` and `downloadArtifact` methods. Heimdall currently has no authenticated GitHub transport adapter, so an enabled call without that adapter returns `status: "unconfigured"`. The injected transport receives fixed owner/repository/workflow filters and the provider's numeric artifact ID; producer URLs are never followed. The archive gate checks run metadata before download, binds manifest/snapshot commits to the authenticated head SHA, validates each metric's run reference and attempt, and applies the frozen schema plus semantic validators.

The accepted source repositories and their slots come from the hash-pinned registries in `registries/`. Snapshot IDs remain opaque contract identifiers; Heimdall enforces immutable ID replay/collision behavior but does not reimplement either producer's ID hash. SagaScript metric sources must use `ref:github-run-{runId}-attempt-{attempt}`. Gille Inference metric sources must use the exact collection ref for the authenticated run and attempt: `complexity`, `knip`, `coverage`, or `ci` suffixes for the corresponding slots. `source.attempt` must match the authenticated attempt. Registered slot fields (language, platform, features, scope and metric versions) are checked. `scope_digest` must satisfy the frozen digest schema and is retained in the frozen `seriesKey`; Heimdall does not claim to recompute producer config/scope digests. A digest change creates a separate series key rather than being silently merged.

The artifact parser accepts the producers' closed manifest and evidence-index formats. It rejects unsafe or duplicate ZIP members, links and special files, unsupported compression, excessive sizes/counts, unknown files and malformed provenance. SagaScript's `scope-registry.json` must equal the pinned registry. It is treated as data and is never executed. Missing registered slots are persisted as explicit unknown gaps. Objective snapshots expire six calendar months after collection. `getObjectiveHistory(db, { repoOwner, repoName, days, asOf })` accepts only 30-, 90-, or 365-day windows; expired history is omitted even when the requested window is longer than retention. `readObjectiveSourceState(db, { repoOwner, repoName, enabled, configured })` returns the last attempted status/time, last successful sample time and a static error code without contacting a source.

Subjective reconciliation uses the existing Munin RPC path: `reconcileSubjectiveEvidence(db, config, { rpc, now })`. Its config defaults disabled. Tests inject the RPC method; production wiring requires an explicitly enabled source configuration and the existing authenticated Munin client. Each request calls `memory_code_health` with required `action: "export"`, the configured namespace and producer principal, exact repo/rubric filters, and a bounded page size. The producer principal must be authorized by the authenticated Munin caller. Heimdall checks the returned namespace, producer and filter hash, plus page watermark, record totals, references, retention metadata and cursor uniqueness. The filter hash follows Munin's canonical `{ namespace, producer, filters }` shape; every omitted filter is `null`, including task, time and model filters. Only a final page marked complete and `complete-authorized-retained-set` can replace the local source set. Failed, invalidated or partial exports keep existing non-expired data. Local expiry still runs during outages, and dependent records are removed when referenced context expires.

`readSubjectiveEvidence(db, config, { now })` is an async, bounded, read-only view used by the page and API. It does not call Munin, load credentials or trigger collection. It returns the last successful source metadata, primary records and their authoritative retention metadata, retained context, a frozen `aggregateRecords` result, and collection status (`unconfigured`, `disabled`, `not-collected`, `committed`, `incomplete`, or `rejected`) with last attempt/success times and a static error code. If no valid source config has ever been supplied, it returns an explicit `unconfigured` state and empty evidence. Expected-attempt inventory is deliberately omitted, so participation denominator/fraction stay unknown.

The focused synthetic backend tests are `test/code-health-backend.test.js`; the migration's focused assertions are under the `openDatabase` tests in `test/db.test.js`. Real GitHub adapter wiring and authorized live end-to-end collection remain pending. UI rendering must use these read-only query methods and must not collect during a request.
